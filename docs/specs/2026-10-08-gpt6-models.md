# GPT-6 models replace GPT-5.6

Codex CLI 0.161.0 lists the GPT-6 lineup and labels every gpt-5.6 model "older
generation". The dev loop moves each role to its GPT-6 successor. Engine names stay
as they are (`luna`, `terra`), because they are stored in engine files across repos;
they name a role, not a model.

| Role | Engine / lane | Old model | New model |
|---|---|---|---|
| Primary (explore, implement) | `luna` | `gpt-5.6-luna` | `gpt-6-luna` |
| Escalation | `terra` | `gpt-5.6-terra` | `gpt-6-astra` |
| Review default | review lane, no `--engine` | `gpt-5.6-sol` | `gpt-6.1-sol` |
| omp review default | `omp` engine, `claude-reviewer` under omp | `openai-codex/gpt-5.6-sol` | `openai-codex/gpt-6.1-sol` |

All four GPT-6 models accept efforts low through max, so the effort defaults stay:
sol at medium, luna and terra at max.

## Requirements

- **R1.** `scripts/codex-run.sh` holds one mapping from engine/profile to model
  (`luna` -> `gpt-6-luna`, `terra` -> `gpt-6-astra`, review default -> `gpt-6.1-sol`).
  Every place that names a GPT model uses it. The `"gpt-5.6-$profile"` string
  templates go away, since `terra` no longer shares its model's name.
- **R2.** `run_gpt` passes `-m <model>` to codex alongside `-p <profile>`, so the model
  in the receipt and the stderr label is the model that actually ran. The review lane
  already passes `-m "$rmodel"`; keep it.
- **R3.** The review lane's effort defaults and `review_fast` rule match the new
  names: `*gpt-6.1-sol` -> medium; `*gpt-6-luna|*gpt-6-astra` -> max; fast mode only
  for `gpt-6-luna`.
- **R4.** `omp_default_model review` and `hooks/pre/charles.ts` (`claude-reviewer`)
  default to `openai-codex/gpt-6.1-sol:medium` / `openai-codex/gpt-6.1-sol`.
- **R5.** `scripts/doctor.sh` checks for `model = "gpt-6.1-sol"` and names gpt-6.1-sol in
  its WARN text.
- **R6.** Docs that describe current behaviour say the new names: `README.md`,
  `skills/charles-flow/SKILL.md`, `agents/codex-reviewer.md`, `commands/engine.md`,
  and the header comment in `codex-run.sh`. Leave `docs/specs/*` from before
  2026-10-08 unchanged: they record past decisions.
- **R7.** `scripts/selftest.sh` assertions that pin model names expect the new names,
  and one new assertion proves R2: a stubbed `codex` on PATH records its argv, and a
  `--lane explore` run with engine `luna` passes `-m gpt-6-luna`.
- **R8.** No `gpt-5.6` string remains anywhere outside `docs/specs/`
  (`git grep -n "gpt-5\.6" -- ':!docs/specs'` prints nothing).
